# 反復と快

AIに映像を作らせると変化が激しくなりがちだが、人間は繰り返しを好むのではないか、というユーザーの直感から調べた。
この直感には複数の分野で裏付けがある。
音楽心理学と、美しさを実験で測る心理学は、適度な反復が快を生み、変化が多すぎると快が下がることを直接扱っている。

## AI映像の変化過多

拡散モデルはフレームを半ば独立に作るため、形や位置が揺れ続ける。[時空間一貫性のサーベイ](https://arxiv.org/pdf/2502.17863)がこの問題を扱っている。
実務者からは、無関係な動きを続けるより、同じゆっくりした寄りを繰り返すほうが映画的だという指摘がある（[BudgetPixel](https://budgetpixel.com/blog/why-ai-videos-feel-fakeand-how-consistency-changes-everything)）。
AI映像の反復不足を、美しさの理論で論じた論文は見つからなかった。
AIの出力は作品の間で均質化するという批判もある（[JAAC](https://academic.oup.com/jaac/article/84/2/218/8661496)）。映像の中の変化過多と、作品の間の均質化は両立する。

## MVへの応用

同じセクションには同じモチーフ、構図、動きを再登場させ、差分は1〜2要素だけにする。
曲全体で使う視覚モチーフは3〜6個に絞り、絵コンテの各ショットにモチーフIDを振る。
背景の動きは1小節か2小節のループにし、カットは拍か小節の頭に乗せる。
止めと一定の寄りを基本にし、大きな変化はサビの頭など曲の山に集める。
毎回のサビでは同じ決めカットを出す。

## 測れる指標

| 指標                         | 取り方                                                  | 判定の考え方                                                     |
| ---------------------------- | ------------------------------------------------------- | ---------------------------------------------------------------- |
| 平均ショット長               | Remotionの定義から取る。参照MVはPySceneDetectで検出する | 参照MVの範囲で判定する                                           |
| カットの拍同期率             | カット位置と拍の位置を比べる                            | 参照MVの範囲で判定する                                           |
| モチーフの再登場率           | 絵コンテのモチーフIDから数える                          | 低すぎたら変化過多と警告する                                     |
| セクション間の視覚の自己相似 | フレームをCLIPで埋め込み、自己相似行列を作る            | 音楽の自己相似行列と相関が高いほど、曲の反復を映像も反復している |
| 動き量の推移                 | フレーム間の差分を取る                                  | 常に高ければ変化過多である                                       |

指標は変化過多を見つける警告に使い、良さの証明には使わない。最終判断は人間が視聴して決める。
