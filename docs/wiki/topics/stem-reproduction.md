# ステム再現による音作りの分析手法

公開されたステムとMIDIがある曲を、パートごとに自分で作り直して原曲と計測で比べる手法である。
作り直した音と原曲の差を数値で詰めていくと、その差を埋めるのに要った操作（EQ量、包絡、ステレオ幅、バスとマスターの処理）が原曲の音作りの計測値になる。
1曲目の結果は[ただ選択があった](../works/フロクロ_ただ選択があった/index.md)にある。
動かし方は`stem-repro`スキル（`docs/skills/stem-repro/SKILL.md`）にある。

## 指標

| 指標           | 定義                                                                                                           |
| -------------- | -------------------------------------------------------------------------------------------------------------- |
| スペクトル差   | 40 Hzからナイキスト周波数までの1/3オクターブ28帯の長時間平均スペクトルを、最大値で揃えて比べた平均絶対差（dB） |
| 包絡差         | 10 msごとのRMSを最大値で揃え、-50 dBで下を切ってから比べた平均絶対差（dB）                                     |
| 音程差         | クロマの平均ベクトルのコサイン距離を10倍した値                                                                 |
| 音色探しの採点 | スペクトル差に包絡差の半分を足した値。詰める段階では音程差と、ノート頭から揃えた包絡の差も足す                 |
| ステレオ幅     | サイドとミッドのRMSの比（dB）。-100 dBを下回るものはモノラルである                                             |
| レベルの伝達   | 10 msのRMSを入力の大きさで3 dB刻みに分け、出力との差の中央値を出したもの。圧縮の効き方がわかる                 |

## ステム同士の分析

曲全体の数値だけでは、どのパートがどこを受け持っているかが分からない。
`interstem`は次の5つを出す。

| 項目                    | 中身                                                                                         |
| ----------------------- | -------------------------------------------------------------------------------------------- |
| band_owner              | 1/3オクターブ帯ごとに、その帯のエネルギーを多く持つ上位3パートと割合                         |
| beat_phase_db           | 1拍を48分割し、位相ごとの平均パワーを4つおきに出したもの。ダッキングや音を短く切る形が見える |
| low_kick_vs_bass        | 150 Hz以下の包絡についての、キックとベースの相関と、キックが持つエネルギーの割合             |
| stereo                  | パートごとのステレオ幅と左右の偏り                                                           |
| section_balance_rel_mix | セクションごとの、ステムの和に対する各ステムのラウドネス                                     |

## 気をつけること

画面なしのSurgeはパッチを読んだ直後の音が変わらない。0.3秒の無音を一度鳴らすと反映される。
音色探しは一部の音色で固まったり落ちたりする。pebbleのプロセスプールで1音色に30秒の制限を付け、超えたものや落ちたものは飛ばす。
採点にピッチを入れないと、ドラム系の音色が旋律パートの上位に混ざる。詰める段階では音程差を足した。
キックを複数発の平均波形に合わせると、位相のずれた尾は打ち消し合って短くなる。パワーで平均してから合わせる。
セクションごとのラウドネスは無音部分を除いて測るため、まばらなステムでは実際より大きく出る。拍の位相ごとのパワーと合わせて読む。
ノイズで作り直した音は低域が漏れる。後でマッチEQを当てて戻す。
ノイズの作り直しは短い窓ほど包絡が合う。「ただ選択があった」ではトップとfillが128点、stringsが64点、シンバルが512点で一番近かった。
マッチEQは最小位相のFIRで2回かける。4095タップの直線位相FIRはアタックの前に音が漏れ、キックやarpの頭が鈍る。1回ではキックのように18 dB近く削る帯域が残る。
小節より細かい音量は、ノートの頭から揃えて合わせる。キックとarp1はこれで包絡差が半分以下になった。
MIDIには鳴っていないノートが混ざる。ノート頭の音量が原曲の上位0.5%から30 dB以上低いノートは除く。
パッチの読み込みはpedalboardの`load_preset`が.vstpresetしか読めず、Surgeの.fxpは読めない。そのためVST3の状態にfxpの中身を差し込んでいる。
マスターの比較では、レベルの伝達が平らかどうかを先に見る。ゲインとピークの処理を分けずにリミッターだけで音圧を上げると、小さい音まで持ち上がって伝達が傾く。
バスの処理を和のピーク基準のリミッターで真似ると、一番大きいところだけを5 dB以上潰す。最大値で揃える包絡差は、そのぶん全体で大きく出る。バスはコンプレッサーで当てはめる。
書き出しは同じ設定でも毎回少し変わる。音色探しの採点は0.3程度ぶれる前提で比べる。
