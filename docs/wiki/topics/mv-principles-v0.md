# MVの良さの原則 草案v0

1曲目「もういっかい」のMVは、曲とMVの体裁は保てたが、中身は良くなかった。
数値の帯に入れるだけでは良いMVにならないので、参照MVが音の出来事ごとに何を判断しているかを言葉で書き起こし、そこから原則を取り出した。
これは草案で、ユーザーが原則と書き起こしの各行に良い悪いの印を付けてから直す。
数値は根拠として添えるだけにし、主役にしない。

## 材料

書き起こしたのは、高密度型2本と静的型2本の4本である。

| 型     | 作品                                                                | 選んだ理由                                          | 書き起こしの番号 |
| ------ | ------------------------------------------------------------------- | --------------------------------------------------- | ---------------- |
| 高密度 | [Symphony in Acid](../works/Max-Cooper_Symphony-in-Acid/index.md)   | ユーザーが「めちゃくちゃかっこいい」と評価した      | SIA-01〜15       |
| 高密度 | [スライ村](../works/稲むり_スライ村/index.md)                       | 好き8曲で、枠とサビの切り替えがはっきりしている     | SLY-01〜13       |
| 静的   | [イシェド](../works/yowanecity_イシェド/index.md)                   | 好き8曲で、9本の中で最も拍に揃っている              | ISH-01〜13       |
| 静的   | [死んでしまったんだ](../works/椎乃味醂_死んでしまったんだ/index.md) | 好き8曲で、一定の音圧で押し切る曲に静的な絵で応える | SHN-01〜13       |

書き起こしは各作品のページの「所見」の中にあり、取り方もそこに書いた。
音は聴いておらず、音の出来事は音量と自動の区切りからの推測である。

## 共通の原則

4本のうち3本以上で同じ判断が見つかったものを原則とした。
右の欄は根拠になった書き起こしの番号である。

| 番号 | 原則                                                                              | 根拠                                   |
| ---- | --------------------------------------------------------------------------------- | -------------------------------------- |
| P01  | セクションの格は、切替の数より先に画面の器の大きさで示す。                        | ISH-04、ISH-07、SLY-02、SLY-06、SIA-01 |
| P02  | サビの直前は、量を一方向に減らすか増やして、次の強拍で何かが起きると予測させる。  | ISH-05、ISH-06、SLY-05、SIA-03、SIA-10 |
| P03  | サビの頭は、強拍のフレームでハードカットし、それまで閉じていたものを一気に開く。  | ISH-07、SLY-06、SIA-04、SIA-11         |
| P04  | 文字の役割をセクションで変え、Aでは読ませる字幕に、サビでは絵の部品にする。       | ISH-04、ISH-08、SLY-02、SLY-07、SIA-05 |
| P05  | 曲全体に一方向の変形の弧を持たせ、終わりで始まりに戻す。                          | SIA-06、SIA-09、SIA-14、SLY-10、SHN-11 |
| P06  | 歌詞や主題の意味は、言葉を出すことではなく画面の状態の変化で言う。                | ISH-09、ISH-12、SHN-06、SIA-04         |
| P07  | 曲全体を1つの見立て（ウェブページ、ゲーム、スクラップ帳など）と固有の質感で包む。 | SIA-01、SLY-01、SHN-03、ISH-01         |
| P08  | 主役の絵を消す区間を作り、主役が戻る、または消えたまま終わることを出来事にする。  | ISH-09、ISH-12、SHN-10、SLY-09         |
| P09  | 切替が少ない区間でも、目が拍を追える動きか明滅を必ずどこかに残す。                | ISH-02、ISH-08、SIA-07、SIA-15         |
| P10  | 強拍の打撃では内容を変えず、色、配置、大きさなどの様式だけを替える。              | SIA-11、SIA-15、ISH-08、SLY-06         |
| P11  | サビの決めカットは回ごとにほぼ同じ構図で出し直し、違いは歌詞か1要素に絞る。       | ISH-11、SLY-11、SHN-12、SHN-13         |
| P12  | 暗転や無地を句読点にして、章が変わることを示す。                                  | SHN-04、SHN-08、ISH-06、SIA-14         |
| P13  | 始まりと終わりを同じ絵か同じ文で対にする。                                        | SIA-14、ISH-13、SLY-13、SHN-13         |

P01の補足として、イシェドはサビで全面切替が毎分約5回と、Aの約35回より少ない。
サビの解放は切替の増加ではなく、黒帯が外れて絵が全画面になることで作られている。
P05の補足として、Symphony in Acidの弧は文字の読みやすさ、スライ村の弧は物語（手紙、村、RPG、戦い）、死んでしまったんだの弧は同じ素材に足される傷である。

## 作品ごとの固有の判断

原則にはしないが、取り込める判断を作品ごとに分けた。

| 番号 | 作品               | 固有の判断                                                             | 根拠           |
| ---- | ------------------ | ---------------------------------------------------------------------- | -------------- |
| U01  | Symphony in Acid   | 文字の密度だけで別の字や人物の肖像を描き、素材を文字のまま絵に変える。 | SIA-12、SIA-13 |
| U02  | Symphony in Acid   | 切替の一部で1フレームだけ別の状態を挟み、1回の打撃を2段で見せる。      | 所見の数値     |
| U03  | イシェド           | 打楽器の連打に合わせて、題名を1〜2フレームおきに点滅させる。           | ISH-02         |
| U04  | スライ村           | サビの頭で題名を8分ごとに1字ずつ出し、刻みを目に見せる。               | SLY-06         |
| U05  | スライ村           | 4:3の小さな枠を物語の距離として使い、最後のサビ前に枠の端から崩す。    | SLY-02、SLY-10 |
| U06  | 死んでしまったんだ | 単色の画面で、赤の量だけで盛り上がりを示す。                           | SHN-05、SHN-07 |
| U07  | 死んでしまったんだ | 歌詞は右端の小さな縦書きにして、絵を見る画面だと決める。               | SHN-02         |

## 「もういっかい」との照合

今回のMV（[設計書](../../../songs/001-mou-ikkai/06-video/design.md)）を、書き出した映像のコンタクトシートと照らした。
判定は満たす、一部、外すの3つで、根拠はこのスレッドで見た画面である。

| 原則 | 判定   | 根拠                                                                                                  |
| ---- | ------ | ----------------------------------------------------------------------------------------------------- |
| P01  | 外す   | 全編が全画面のベタ塗りで、器の大きさはセクションで変わらない。                                        |
| P02  | 一部   | Bで切替を1小節、2拍、1拍と加速させたが、画面に出る量は増えも減りもしない。                            |
| P03  | 満たす | サビの頭は強拍のフレームでハードカットしている。ただし開くべき閉じたものがないため、解放感は弱い。    |
| P04  | 一部   | Aとサビで歌詞の行はほぼ同じ大きさで、サビでも字幕のままである。DropとBreakの1字だけは絵になっている。 |
| P05  | 外す   | 最初と最後で同じ5色、5配置、1書体のままで、3回のサビの違いは色1つである。進む方向がない。             |
| P06  | 外す   | 「擦り切れるまで」「ノイズ混じり」は文字で出すだけで、画面は擦り切れもノイズも起こさない。            |
| P07  | 一部   | 再生バーと回数カウンタで録音の見立てを置いたが、画面の1割に満たない飾りで、質感はベタ塗りだけである。 |
| P08  | 外す   | 主役（フック札）は最初から最後まで同じ形で出続け、消える区間がない。                                  |
| P09  | 外す   | AとBridgeは毎分0〜2.5回の切替で、動くものがカラオケ式の色替えしかない。                               |
| P10  | 満たす | サビの切替はフック札の文字を変えずに背景の色だけを替えている。                                        |
| P11  | 満たす | Chorus1と2は同じ規則で同じカット割りになっている。                                                    |
| P12  | 満たす | B1とBreakの末尾に黒の無音を置いている。                                                               |
| P13  | 満たす | 再生バーのループで始まり、灰色の「またね」で終えている。                                              |

満たした5つ（P03、P10〜P13）は、どれも反復と同期の規則として書ける。
外した5つ（P01、P05、P06、P08、P09）は、曲全体を通した変化の方向と、意味を画面の状態に置き換える判断だった。
一部にとどまった3つ（P02、P04、P07）も、規則は置いたが画面の量や役割を動かしていない点で同じ側に入る。
この照合から見ると、「もういっかい」は規則の反復はできていたが、曲の時間に沿って画面が何かになっていく弧を欠いていた。

## 次の手順

ユーザーが原則（P01〜P13）、固有の判断（U01〜U07）、各作品の書き起こし行に良い悪いの印を付ける。
印の付いた原則だけを残し、絵コンテを作る前の確認項目にする。
数値で測れる原則（P03、P09〜P12）は、印が付いたら自己解析の検査に足す。
