# 好みプロファイル

ユーザーが好きな曲として挙げた8曲から、好みの傾向をまとめる。
「良い曲」は定義せず、この8曲の範囲を判定の物差しにする。
音源はリポジトリに入れず、統計値だけを[taste-refs-v1.json](../data/taste-refs-v1.json)に残す。

## 読み取れる傾向

音圧はかなり高い。統合ラウドネスの中央値は-6.3 LUFSで、範囲は-9.8から-4.5に収まる。
帯域は低域が厚く、高域は控えめである。60〜250 Hz帯が最も強く、6 kHz以上は全曲で-13 dB以下である。
8曲中6曲は音量の起伏が8 dB以上あり、静かな部分から爆発する構成が多い。Rememberと死んでしまったんだは一定の音圧で押し切る型である。
テンポとキーは幅広く、好みの決め手ではないと見ている。
歌声を確かめた6曲のうち4曲が合成音声である。イシェドとSTARGAZERの歌声はまだ確かめていない。

true peakは非可逆音声のデコードで0 dBTPを超えるため、解析から外した。

## 映像の好み

ユーザーは音MADがとても好きで、その手法を映像に取り込みたいと考えている。曲に取り込むのは難しいと見ている。
想定する手法は、拍や音にフレーム単位で同期したカット、ズーム、フラッシュと、音の頭に合わせた素材の反復や反転である。
測れる指標は、カットと拍の同期率、1拍あたりのカット数、音の頭と映像の変化の一致率である。
Remotionでは、解析した拍や音の頭の時刻表をそのまま映像のイベントに使える。

映像の反復については[反復と快](repetition-aesthetics.md)にまとめている。
