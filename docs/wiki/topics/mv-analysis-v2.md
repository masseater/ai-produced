# MV分析v2

好き8曲とSymphony in AcidのMVを、全フレーム単位で測り直した結果をまとめる。
最初の分析（v1）はカット数と知覚ハッシュに頼り、2フレーム以内のカットを1つにまとめたため、1フレームだけ挟まる状態と、色や配置だけを変える反復を取りこぼした。
ユーザーの「人間の目は1F単位で見える」という指摘を受けて、手法を作り直した。
9本の統計は[mv-analysis-v2.json](../data/mv-analysis-v2.json)、各作品の値は作品ディレクトリのanalysis-v2.jsonにある。

## 手法

映像は256x144に縮小した全フレームで、明るさ、色ヒストグラム、エッジの差分、CLIP（ViT-B/32）の埋め込み、知覚ハッシュを記録した。
画面の変化は32x18に縮小した構図の差で3段階に分けた。
構図の差が25以上で、内容（CLIPの1-cos）が0.2以上か、前後3フレームより2倍以上跳ねているか、色の差が0.5以上のものを全面切替とした。
構図の差が8から25のものを部分切替、それ未満の細部の変化を局所変化とした。
1フレームだけの状態は、元に戻るフラッシュ（A→B→A）と、次の状態へ進む2段切り替え（A→B→C）に分けて数えた。
同期は拍、8分、16分の格子に対して±0フレームと±1フレームで測り、格子がフレームを覆う割合をランダム基準にした。
BPMは、定テンポの格子と音の頭の一致度（±25ms）を候補ごとに比べて決めた。
反復は、2Hzで取ったCLIPの埋め込みが10秒以上離れた場面と似ている割合（cos 0.92以上）と、1秒ごとのOCR文字列のあいまい一致で測った。
判読性（OCRの文字数と信頼度、エッジ密度、エントロピー、彩度）は短期ラウドネスとの相関を取った。
閾値は、全面切替の各段階からランダムに6組ずつ取り出して目で確かめて決めた。

実写のカメラ移動や紙吹雪は全面切替に誤って入り、Cheerleaderでは2〜3割が誤検出と見ている。
映像と音の最適なずれは作品ごとに-4〜3フレームあり、±0フレームの一致率はこのずれを補正していない。
区間の分割は音声だけで行った。OCRは小さい日本語を読み誤ることが多い。
スクリプト（mvan.pyとsummarize.py）はリポジトリに入れず、プロジェクトの共有フォルダに置いた。

再登場率は、2Hzで取った場面のうち10秒以上離れた場面とCLIPのcosが0.92以上になる割合である。
この値は絵の似具合を測るため、同じ文を色と配置だけ変えて出す反復は拾えない。Symphony in AcidはCLIPでは8%だが、OCR文字列では64.7%が別の場面にも出る。
私だけの魔法。と死んでしまったんだのBPMは、ユーザーが確認して検出値の倍を採った値である。
格子と音の頭の一致度は、半分のBPMのほうが高い。
まにまにのBPMは117.5と172.3で格子との一致度が同程度（1.14と1.16）で決まらず、表の一致率は117.5の格子の値である。

## 読み取れる傾向

映像は、ほとんど止まった絵で見せる静的型と、毎分30回以上切り替える高密度型に分かれる。
静的型はSTARGAZER、まにまに、Remember、イシェド、死んでしまったんだの5本である。
静的型の全面切替は毎分0〜17回、再登場率は17〜98%である。
高密度型はSymphony in Acid、私だけの魔法。、Cheerleader、スライ村で、全面切替は毎分33〜157回、再登場率は1〜8%である。
全面切替が拍か8分の格子に±0フレームで揃う度合いは、ランダム基準との比でイシェドが4.1倍、スライ村が2.4倍、死んでしまったんだが1.4倍で、ほかはほぼ1倍である。
切替の多さと拍への同期は別の軸で、最も拍に揃うイシェドは切替が2番目に少ない。
1フレームだけの状態はほぼすべて2段切り替えで、元に戻るフラッシュはCheerleaderの7回、イシェドと私だけの魔法。の1回ずつしかない。
音MADで定番の1フレームの反転フラッシュは、好き8曲のMVではほとんど使われていない。

帯域ごとの音量は、9本の平均±標準偏差で次のとおりである。

ばらつきは60〜250 Hzで最も小さく、この帯域の厚さは9本に共通している。
