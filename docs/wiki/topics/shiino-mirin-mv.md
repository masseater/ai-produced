# 椎乃味醂のMV

ユーザーのニコニコ動画の公開マイリストには、椎乃味醂の曲が9曲入っている。
そのMVを同じ手順で書き起こし、椎乃味醂のMVに共通する判断を原則の草案にまとめた。
参照MV全体の原則は[MVの良さの原則 草案v0](mv-principles-v0.md)にあり、この頁はその椎乃味醂版にあたる。
ユーザーが原則と書き起こしの各行に良い悪いの印を付けてから直す。

## 対象と手順

9曲はすべて長さがちょうど180秒で、投稿は2020年12月から2023年8月にかけてである。
映像はどれも椎乃味醂が企画か演出を担い、6曲で柚璃遥が構成やコラージュを担っている。
YouTubeの公式の720pの映像を家のMacで取り直し、2秒に1枚のコンタクトシートと、自動で分けた区切りの前後1.5秒の全フレームを目で見た。
区切りは音声の特徴量を拍ごとに束ねて分けたもので、音は聴いていない。
音の出来事は音量と区切りからの推測として書いた。
ユーザーから、1〜2F単位で演出が大きく変わるのを追えていないと指摘を受け、2026-10-10に9本の全フレームを測り直した。
その結果は[フレーム単位の測り直し](#フレーム単位の測り直し)の節と、各作品のフレーム単位の書き起こし（番号にFが付く）にある。

## フレーム単位の測り直し

2秒に1枚の見方では、9曲のうち7曲が1枚の絵を長く保つ静的型に見えた。
全フレームで測ると、その間も絵は止まっていなかった。
構図を保ったまま、線、質感、色、明るさを1〜4Fの単位で変え続けている。
2026-10-10に、さらに全フレームを連番のシートにして全部の変化点を目で見直し、各作品に「フレーム単位の書き起こし v2」を足した。

### 測り方

絵の更新の数とコマ打ちは、ffmpegの公式フィルタmpdecimate（既定の値）で測った。
mpdecimateが前のコマと同じとみなして落とさなかったコマを「更新されるコマ」とし、更新どうしの間隔（8F以下）の最頻を「コマ打ち」とした。
mpdecimateは8×8の区画ごとに差を見るので、狭い範囲の線の揺れも拾う。
カットの中だけで動くコマの割合は、mpdecimateでは切り替えと区別できないため、全フレームの隣どうしの画素差を数える小さなスクリプトで別に測った。
320×180の灰色で12階調を超えて変わる画素が0.2%以上あり、半分未満しか変わらず、暗転でもないコマを、カットの中で動くコマとした。
2F以下しか続かない状態と、その前後のコマは、連番のコマの帯と差分の図を作って目で確かめた。

| 作品                           | fps | 更新されるコマ | 主なコマ打ち     | カットの中で動くコマ | 2F以下の状態     | 多いカットの長さ |
| ------------------------------ | --- | -------------- | ---------------- | -------------------- | ---------------- | ---------------- |
| じゃあ君の思想が死ねばいい     | 24  | 33%            | 3コマ（82%）     | 33%                  | 3                | 8F               |
| 痛みなんていらなかった         | 30  | 21%            | 4コマ（48%）     | 10%                  | 1                | 5F、10F          |
| ただ一度とないあの夏へ         | 24  | 46%            | 1コマ、3コマ     | 29%                  | 32               | 1F、2F           |
| ヘテロドキシー                 | 24  | 30%            | 2コマ、4コマ     | 12%                  | 0                | 6F以上           |
| 死んでしまったんだ             | 24  | 40%            | 2コマ（59%）     | 29%                  | 18               | 4F、10F          |
| この命を響かせたいと思ったのだ | 24  | 64%            | 1コマ、2コマ     | 47%                  | 20               | 5F（37回）、6F   |
| 知っちゃった                   | 24  | 72%            | 1コマ（68%）     | 51%                  | 3                | 9F               |
| あなたにはなれない             | 24  | 76%            | 1コマ（72%）     | 61%                  | 315              | 2F（78回）、3F   |
| OSINT                          | 24  | 75%            | 1コマ（70%）     | 62%                  | 355              | 8F（73回）       |
| もういっかい（1曲目）          | 48  | 10%            | 決まった間隔なし | 2%                   | 56（2Fのカット） | 18F（157回）、9F |

9曲はどれも全体の2割以上のコマで絵が更新され、作品ごとに決まった間隔がある。
もういっかいは48fpsのうち1割しか更新されず、その大半は文字の切り替えで、カットの中で動くコマは2%しかない。

### フレーム単位の原則

各作品の「フレーム単位の書き起こし v2」は、全フレームを連番のシートにして全部の変化点を前後のコマと見比べたものである。
その目立つ手法（K番号）のうち、9曲中5曲以上で同じ判断が見つかったものを原則とした。
v1の行（F番号）も根拠に残した。

| 番号 | 原則                                                                                                  | 根拠                                                                                                                         |
| ---- | ----------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| F01  | 構図を保つ間も、作品ごとに決めたコマ打ち（2〜5コマ、0.5秒ごとの質感替え）で線や質感を差し替え続ける。 | HTR-K01、HTR-K02、SHN-K06、KIN-K03、OSI-K09、ANA-K08、ITM-K06、SHT-K08、NTS-K09、JSN-F01                                     |
| F02  | 場面の間に黒（紺黒や灰の無地を含む）を挟み、その長さを決まったフレーム数の組から選ぶ。                | SHN-K01、JSN-K06、KIN-K01、SHT-K01、ITM-K03、OSI-K06、ANA-K05、HTR-K03                                                       |
| F03  | 新しい絵を1枚で出さず、色ずれ、光漏れ、線画、色入れ、明るさや寄りの段を1〜5Fずつ踏んでから出す。      | KIN-K02、SHT-K02、SHT-K03、JSN-K01、JSN-K02、NTS-K01、NTS-K06、ITM-K02、ITM-K05、ANA-K02、HTR-K04、HTR-K05、HTR-K06、SHN-K08 |
| F04  | 前に出した素材を、尺をほぼ保ったまま色、向き、版を替えて戻す。                                        | SHN-K03、OSI-K02、NTS-K03、SHT-K05、KIN-K06、JSN-K05、ITM-K07、ANA-K09、HTR-K07                                              |
| F05  | 切り替えの長さを拍の格子にそろえ、同じ長さの単位を繰り返す。                                          | ITM-K01、OSI-K01、ANA-K01、KIN-K03、SHT-K01                                                                                  |
| F06  | 長い静止の中でも、数秒から数十秒かけて要素を足すか、明るさや寄りを少しずつ変える。                    | SHN-K04、SHN-K09、SHT-K07、ITM-K08、NTS-K10、HTR-K08、HTR-K10、JSN-K07                                                       |
| F07  | 黒の上に右端の縦書きの歌詞だけを残し、絵より先に言葉を出す。                                          | SHN-K02、HTR-K03、JSN-K06                                                                                                    |

F07は3曲だけで原則の基準に届かないが、M01（歌詞は右端の小さな縦書き）と合わせて残した。
1Fだけ別の状態を挟んで元に戻す手順（A→B→A）は、あなたにはなれない（ANA-K03）とこの命を響かせたいと思ったのだ（KIN-K08）にしかない。
1〜2Fの挟みのほとんどは、次の状態へ進む段（A→B→C）として使われている。
人物が出る最初の数Fだけ色をピンクや赤にずらして落ち着かせる手順は、知っちゃった（SHT-K03）とこの命を響かせたいと思ったのだ（KIN-K02）にある。

## 「もういっかい」との照合

1曲目のMV（[設計書](../../../songs/001-mou-ikkai/06-video/design.md)）を、書き出した映像のコンタクトシートと照らした。

| 原則 | 判定   | 根拠                                                                                            |
| ---- | ------ | ----------------------------------------------------------------------------------------------- |
| M01  | 外す   | 歌詞そのものを画面の主役にし、フック「もういっかい」を35回大きく出している。                    |
| M02  | 一部   | 赤を強調色にしたが、赤と黄の全面の背景も使うので、赤が1点のアクセントになっていない。           |
| M03  | 外す   | 最初から最後まで同じ5色と同じ明るさで、最後のサビに取っておいた明るさがない。                   |
| M04  | 外す   | 色のない状態から色を足す手順がなく、語りの行を灰色から黒へ替えるだけである。                    |
| M05  | 外す   | 物や風景の絵も人物の絵もなく、全編が文字だけである。                                            |
| M06  | 一部   | B1とBreakの末尾に黒の無音を置いたが、空白の長さで区切りの格を変えてはいない。                   |
| M07  | 一部   | AとBridgeは切り替えが少ないが、保つ絵がないので画面が止まって見える。サビは全編で密にしている。 |
| M08  | 満たす | Chorus1と2は同じカット割りで、差分は黄色の1色である。                                           |
| M09  | 外す   | フック札は最後まで同じ形で出続け、消える区間がない。                                            |
| M10  | 一部   | 再生バーと回数カウンタを置いたが、全編に常に出ており、1回だけ挟む文書になっていない。           |
| M11  | 満たす | 再生バーのループで始まり、灰色の「またね」で終えている。                                        |
| F01  | 外す   | カットの間で動くコマは2%しかなく、切り替えまでの文字は止まったままである。                      |
| F02  | 一部   | B1とBreakの末尾に黒を置いたが、場面の間に黒を挟む作りではなく、黒の長さも組になっていない。     |
| F03  | 外す   | ハードカットだけで、新しい画面を段を踏まずに1枚で出している。                                   |
| F04  | 満たす | Chorus1と2を同じカット割りと尺で出し直し、色だけを替えている。                                  |
| F05  | 満たす | カットの長さは18F（48fpsで160 BPMの1拍）と9F（8分音符）に集まっている。                         |
| F06  | 外す   | 長い区間でも画面の要素は増えも減りもせず、明るさも変わらない。                                  |
| F07  | 外す   | 歌詞が画面の主役で、黒の上に言葉だけを先に出す手順はない。                                      |

満たしたのは4つ、一部が5つ、外したのが9つだった。
フレーム単位で見ると、いちばん大きな差はF01である。
もういっかいはカットの長さを拍にそろえたが、カットの中の絵は止めたままにした。
椎乃味醂の9曲は、切り替えの少ない区間でも絵を2〜5コマの単位で動かし続け、新しい絵は段を踏んで出している。
「もういっかい」はSymphony in Acidを手本に、文字だけの高密度型を選んだ。
ユーザーがマイリストに9曲を入れている椎乃味醂のMVは、ほとんどが1枚の絵を長く保つ静的型で、歌詞を脇に置いている。
手本の選び方そのものが、ユーザーの好みとずれていた可能性がある（推測）。

## 次の手順

ユーザーが原則（M01〜M11、F01〜F07）、固有の判断（V01〜V16）、各作品の書き起こし行に良い悪いの印を付ける。
印が付いた原則を、[MVの良さの原則 草案v0](mv-principles-v0.md)の原則と突き合わせて1つにまとめる。
