# 椎乃味醂のMV

ユーザーのニコニコ動画の公開マイリストには、椎乃味醂の曲が9曲入っている。
そのMVを同じ手順で書き起こし、椎乃味醂のMVに共通する判断を原則の草案にまとめた。
参照MV全体の原則は[MVの良さの原則 草案v0](mv-principles-v0.md)にあり、この頁はその椎乃味醂版にあたる。
ユーザーが原則と書き起こしの各行に良い悪いの印を付けてから直す。

## 対象と手順

9曲はすべて長さがちょうど180秒で、投稿は2020年12月から2023年8月にかけてである。
映像はどれも椎乃味醂が企画か演出を担い、6曲で柚璃遥が構成やコラージュを担っている。
YouTubeの公式の720pの映像を家のMacで取り直し、2秒に1枚のコンタクトシートと、自動で分けた区切りの前後1.5秒の全フレームを目で見た。
区切りは音声の特徴量を拍ごとに束ねて分けたもので、音は聴いていない。
音の出来事は音量と区切りからの推測として書いた。

## 共通の原則

9曲のうち5曲以上で同じ判断が見つかったものを原則とした。
根拠の欄は書き起こしの番号である。

| 番号 | 原則                                                                                   | 根拠                                           |
| ---- | -------------------------------------------------------------------------------------- | ---------------------------------------------- |
| M01  | 歌詞は右端の小さな縦書きにして主役にせず、題名を大きく出すのは終盤の1回だけにする。    | SHN-02、JSN-08、ITM-08、SHT-03、KIN-01         |
| M02  | 1作品の色を1つの色相に絞り、赤やピンクは1点のアクセントとしてだけ使う。                | SHT-04、KIN-07、ITM-01、ANA-02、SHN-05         |
| M03  | 明るさか彩度の最大を、最後のサビまで取っておく。                                       | SHT-10、KIN-09、ITM-07、NTS-09、HTR-08、OSI-07 |
| M04  | 同じ絵をまず色なしで見せ、同じ構図のまま色を足して出来事にする。                       | JSN-01、JSN-02、HTR-01、HTR-02、NTS-08         |
| M05  | Aは物や風景の切り貼りで語り、人物の絵はサビや山場に取っておく。                        | SHT-03、SHT-06、KIN-03、NTS-03、NTS-04、ANA-01 |
| M06  | 暗転を句読点に使い、空白の長さで区切りの格を変える。                                   | SHN-04、SHT-09、ITM-05、HTR-05、OSI-08         |
| M07  | 1枚の絵を10秒以上保つことを基本にし、密な切り替えは決めた区間だけに集める。            | JSN-04、HTR-08、KIN-05、ANA-06、OSI-03         |
| M08  | 2番は1番と同じ絵や手順を出し直し、差分は色、人数、姿勢のどれか1つにする。              | SHT-07、JSN-05、JSN-06、ANA-07、NTS-07、HTR-06 |
| M09  | 主役を画面から一度外し、不在を空いた画面で示す。                                       | ITM-02、KIN-08、ANA-01、NTS-05、SHN-10         |
| M10  | 新聞、エラー表示、投稿ページ、読めない記号の列などの文書を挟み、歌詞の外の文脈を足す。 | NTS-02、KIN-07、ANA-10、ITM-04、OSI-01         |
| M11  | 冒頭の素材や場面に戻って閉じる。                                                       | SHT-11、ITM-08、SHN-13、NTS-06、OSI-08         |

M06の補足として、死んでしまったんだの暗転はほぼ12.8秒ごと（8小節ごとと見られる）に15回入る。
空白は、音の構成の格子そのものとして使われている。
M07の補足として、あなたにはなれないはAで毎分5〜26回、サビで毎分約430回と、密度の差そのものを構成にしている。
OSINTは3つの章の終わりにだけ密な区間を置き、3回目を最も密にしている。

## 「もういっかい」との照合

1曲目のMV（[設計書](../../../songs/001-mou-ikkai/06-video/design.md)）を、書き出した映像のコンタクトシートと照らした。

| 原則 | 判定   | 根拠                                                                                            |
| ---- | ------ | ----------------------------------------------------------------------------------------------- |
| M01  | 外す   | 歌詞そのものを画面の主役にし、フック「もういっかい」を35回大きく出している。                    |
| M02  | 一部   | 赤を強調色にしたが、赤と黄の全面の背景も使うので、赤が1点のアクセントになっていない。           |
| M03  | 外す   | 最初から最後まで同じ5色と同じ明るさで、最後のサビに取っておいた明るさがない。                   |
| M04  | 外す   | 色のない状態から色を足す手順がなく、語りの行を灰色から黒へ替えるだけである。                    |
| M05  | 外す   | 物や風景の絵も人物の絵もなく、全編が文字だけである。                                            |
| M06  | 一部   | B1とBreakの末尾に黒の無音を置いたが、空白の長さで区切りの格を変えてはいない。                   |
| M07  | 一部   | AとBridgeは切り替えが少ないが、保つ絵がないので画面が止まって見える。サビは全編で密にしている。 |
| M08  | 満たす | Chorus1と2は同じカット割りで、差分は黄色の1色である。                                           |
| M09  | 外す   | フック札は最後まで同じ形で出続け、消える区間がない。                                            |
| M10  | 一部   | 再生バーと回数カウンタを置いたが、全編に常に出ており、1回だけ挟む文書になっていない。           |
| M11  | 満たす | 再生バーのループで始まり、灰色の「またね」で終えている。                                        |

満たしたのは2つ、一部が4つ、外したのが5つだった。
「もういっかい」はSymphony in Acidを手本に、文字だけの高密度型を選んだ。
ユーザーがマイリストに9曲を入れている椎乃味醂のMVは、ほとんどが1枚の絵を長く保つ静的型で、歌詞を脇に置いている。
手本の選び方そのものが、ユーザーの好みとずれていた可能性がある（推測）。

## 次の手順

ユーザーが原則（M01〜M11）、固有の判断（V01〜V08）、各作品の書き起こし行に良い悪いの印を付ける。
印が付いた原則を、[MVの良さの原則 草案v0](mv-principles-v0.md)の原則と突き合わせて1つにまとめる。
