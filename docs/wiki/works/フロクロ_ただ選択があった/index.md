## 所見

キックとベースは帯域と時間の両方で分けている。
70〜80 Hzを境に下をキック、上をベースが持ち、150 Hz以下の包絡の相関は0.09しかない。
キックは1拍の前半で鳴りきり、拍の7/12あたりから急に切れる。
キックのピッチは約260 Hzから20 msで115 Hz、50 msで68 Hz、140 ms以降は41 Hz付近まで長く下がる。
arp1は16分ごとに鋭く切られ、ピアノは拍の中でほぼ平らに伸びる。
マリンバは裏拍側が強く、stringsは拍頭に向かって盛り上がって切れる逆再生のような形である。
ベースにも広がりがあり、サイドがミッドの-5.5 dBある。synthは左に6 dB寄せてある。
ドラムとfillが前に出て、上物は10 dB前後下げてある。
バスでは軽い圧縮でピークだけを約2 dB抑え、マスターでは約10 dB持ち上げてキックのピークを最大12 dB潰している。
True Peakの余裕は取っていない。

マスタリングはほぼ一定のゲインと、上端のピークだけを潰す処理である。
入力の大きさで分けると、上端3 dBを除いて持ち上げ量は10.2〜11.1 dBに収まり、小さい音だけを持ち上げる圧縮はしていない。

自分で作り直したv2の結果は次のとおりである。v1は音色を探しただけ、v2は音色の包絡を最適化し、音量の操作を原曲に合わせた。

| ------- | ---------------- | ---------------- | -------------------------------- |
| kick    | 7.2              | 3.7              | 胴の長さを含めたキックの当てはめ |
| bass    | 6.2              | 4.6              | 音色の包絡の最適化               |
| piano   | 4.6              | 2.7              | 小節ごとの音量（約6 dBの段差）   |
| marimba | 4.7              | 3.1              | 拍の頭を5〜8 dB下げ、裏を残す    |
| strings | 6.4              | 3.9              | 短い窓でのノイズ再合成           |
| arp1    | 7.4              | 6.9              | 16分ごとに後半を10〜12 dB下げる  |
| arp2    | 10.9             | 7.5              | 音色の包絡と拍内の音量           |
| synth   | 12.9             | 10.9             | 拍の前半の後ろを16〜21 dB下げる  |

原曲のピアノは、MIDIのまま鳴らした音より24〜31小節と40〜55小節で3〜7 dB大きく、32〜39小節と56小節以降で2〜3 dB小さい。
arp1とsynthは拍の中の音量の形を合わせても差が残り、音色の時間の形がまだ合っていない。
synthは31〜32小節にしか鳴っておらず、包絡差の大部分は鳴り終わりの長さの違いである。
ミックスはスペクトル差0.69 dB、ステレオ幅-9.2 dB（原曲-9.4 dB）まで合った。
マスターは-7.5 LUFS、スペクトル差0.72 dB、クレスト9.7 dB（原曲8.1 dB）で、クレストの差が残った。

## 参考にする点

キックとベースは70〜80 Hzで上下に分け、低域の包絡はキックとベースで連動させない。
キックは長いピッチ下降と約200 msの胴を作り、次の拍の前に切る。
上物はパートごとに拍の中の居場所（16分で短く切る、裏拍、拍頭に向けた盛り上がり）を変え、ラウドネスはドラムより10 dB前後下げる。
ミックスバスではピークだけを2 dBほど抑え、マスターでは一定のゲインで-7.5 LUFSまで上げて、上端のピークだけをクリッパーで潰す。
パートの音量は区間ごとに動かし、上物は拍の中で鳴る位置ごとに音量を作る。
