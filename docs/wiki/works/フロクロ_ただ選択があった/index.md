## 所見

キックとベースは帯域と時間の両方で分けている。
70〜80 Hzを境に下をキック、上をベースが持ち、150 Hz以下の包絡の相関は0.09しかない。
キックは1拍の前半で鳴りきり、拍の7/12あたりから急に切れる。
キックのピッチは約260 Hzから20 msで115 Hz、50 msで68 Hz、140 ms以降は41 Hz付近まで長く下がる。
arp1は16分ごとに鋭く切られ、ピアノは拍の中でほぼ平らに伸びる。
マリンバは裏拍側が強く、stringsは拍頭に向かって盛り上がって切れる逆再生のような形である。
ベースにも広がりがあり、サイドがミッドの-5.5 dBある。synthは左に6 dB寄せてある。
ドラムとfillが前に出て、上物は10 dB前後下げてある。
バスでは軽い圧縮でピークだけを約2 dB抑え、マスターでは約10 dB持ち上げてキックのピークを最大12 dB潰している。
True Peakの余裕は取っていない。

マスタリングはほぼ一定のゲインと、上端のピークだけを潰す処理である。
入力の大きさで分けると、上端3 dBを除いて持ち上げ量は10.2〜11.1 dBに収まり、小さい音だけを持ち上げる圧縮はしていない。

自分で作り直したv2の結果は次のとおりである。v1は音色を探しただけ、v2は音色の包絡を最適化し、音量の操作を原曲に合わせた。

原曲のピアノは、MIDIのまま鳴らした音より24〜31小節と40〜55小節で3〜7 dB大きく、32〜39小節と56小節以降で2〜3 dB小さい。
arp1とsynthは拍の中の音量の形を合わせても差が残り、音色の時間の形がまだ合っていない。
synthは31〜32小節にしか鳴っておらず、包絡差の大部分は鳴り終わりの長さの違いである。
ミックスはスペクトル差0.69 dB、ステレオ幅-9.2 dB（原曲-9.4 dB）まで合った。
マスターは-7.5 LUFS、スペクトル差0.72 dB、クレスト9.7 dB（原曲8.1 dB）で、クレストの差が残った。

キックは227発とも同じ音で、強さのばらつきは5〜95%で0.91〜1.00倍に収まる。
キックの音量包絡は、合わせた音のままだと拍の7/12あたりで2.6 dB足りず、胴を長めに保ってから切っている。
arp1はノートの終わりから30 msで-60 dBまで下げる切り方が一番近く、ノートの間は無音である。
ベースの残りの差は帯域ごとの時間変化で、400 Hz〜4 kHzの包絡差が6 dBある。音色の明るさがノートの中で動く形がまだ合っていない。
arp2はbasic-pitchの採譜を使った。MuScriptorの採譜に替えると包絡差は8.1 dBに悪化した。

バスは和のピークから9 dB下、比2、アタック0.5 ms、リリース50 msのコンプレッサーが一番近く、ミックスのクレストは19.5 dB（原曲19.4 dB）になった。
マスターは-1 dBを天井にしたソフトクリッパーを、オーバーサンプリングせずにかけると、クレスト8.0 dB（原曲8.1 dB）、True Peak +1.8 dB（原曲+1.4 dB）になった。
クリッパーの前にリミッターを足しても近づかなかった。最上位3 dBの音だけは、原曲が5 dB多く潰していて合っていない。

ベースの倍音は、30 ms以降の3〜6倍音がv3の音色では原曲より4〜8 dB弱かった。初期音色から組んだ音では差が±2.5 dBに収まった。
原曲のarp2は、鳴り始めから80 msで4倍音より上が-45 dB前後まで落ちる。フィルターの包絡で素早く暗くしている。
synthの倍音は奇数が強く（2倍音-20 dB、4倍音-37 dB）、残差も位相の構造を持つ。のこぎり波と矩形波にノイズを足す組み方では届かなかった。
ミックスは包絡差2.3 dB（v3は2.6 dB）、クレスト19.3 dB（原曲19.4 dB）になった。
マスターは-7.5 LUFS、クレスト8.0 dB、True Peak +1.8 dBで、レベル伝達の最大差は3.3 dB（v3は3.7 dB）に縮んだ。

## 参考にする点

キックとベースは70〜80 Hzで上下に分け、低域の包絡はキックとベースで連動させない。
キックは長いピッチ下降と約200 msの胴を作り、次の拍の前に切る。
上物はパートごとに拍の中の居場所（16分で短く切る、裏拍、拍頭に向けた盛り上がり）を変え、ラウドネスはドラムより10 dB前後下げる。
ミックスバスでは速いアタックの比2のコンプレッサーでピークを2 dBほど抑え、マスターでは一定のゲインで-7.5 LUFSまで上げて、上端のピークだけをオーバーサンプリングしないクリッパーで潰す。
パートの音量は区間ごとに動かし、上物は拍の中で鳴る位置ごとに音量を作る。
短く刻むarpはノートの終わりで素早く無音まで切り、ノートの間に残響を残さない。
