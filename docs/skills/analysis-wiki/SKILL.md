# 分析wikiの書き方

1作品を1ディレクトリとして`docs/wiki/works/`に置き、複数の作品にまたがる知見は`docs/wiki/topics/`に置く。
索引は作らない。ページを足せばapps/wikiの一覧と検索に入る。

## 作品ページ

1. 作品の正規URLを1つ決め、`grep -rF "url: $url" docs/wiki/works`で同じ作品のページを探す。あれば書き換えて分析日を更新する。
2. 無ければ`docs/wiki/template.md`を写し、`works/<作者>_<作品名>/index.md`として作る。
3. テンプレートの見出しを順番どおりに埋める。書けない見出しは消さずに「未分析」と書く。

ディレクトリ名の空白は「-」に置き換え、パスに使えない記号は除く。作者が複数なら「-」でつなぐ。
frontmatterの`kind`はsong、mv、otomad、lyric-videoのどれかにし、作品の束は`tags`で表す。

## 本文

推測は推測と明記し、確かめた事実と分ける。
本文は箇条書きにせず、1行1文の地の文で書く。

## データ

解析した数値の元データはJSONで置き、名前に版（-v1など）を付ける。
1作品だけのデータはその作品のディレクトリに、複数の作品をまとめた統計だけを`docs/wiki/data/`に置く。
音源、歌詞の全文、音源から抜き出したMIDIは `reference-materials` スキルに従い、このリポジトリに入れない。
