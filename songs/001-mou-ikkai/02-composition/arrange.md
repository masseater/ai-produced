# 001「もういっかい」アレンジメモ

楽譜は score.toml に書き、MIDIはそこから生成する。`tools/score-midi` が generated/ にMIDIと歌の割り付け表を書き出す。

## コード進行

1小節に1コードである。

| セクション            | 小節                  | 進行                                                 |
| --------------------- | --------------------- | ---------------------------------------------------- |
| Intro、A、Drop、Outro | 1–24ほか              | F#m – D – E – C#m                                    |
| B                     | 25–32、65–72          | D – E – F#m – F#m / D – E – C#sus4 – C#              |
| Chorus                | 33–48、73–88、113–128 | D – E – C#m – F#m（IV–V–iii–vi）                     |
| Bridge                | 89–104                | Bm – C#m – D – E を各2小節                           |
| Break                 | 105–112               | F#m – D – E – C#m – D – E – C# – 無音                |
| LastChorus延長        | 129–136               | D – E – F#m – F#m を2回、136小節目は頭の一撃で止める |

フックは毎回D – Eの上に来る。同じ素材を同じ和声で鳴らし、聞き手が同じ断片だと認識できるようにした。
Outroは前奏と同じC#mで終わり、曲頭へ戻るループとして閉じる。

## メロディ

フック「もういっかい」は1小節で、音程はE4 – F#4 – A4 –（っ）– C#5 – B4 である。
「か」を2拍目の裏へ食わせて最高音C#5に置いた。35回すべて同じ音程とリズムである。

Introの4回は、語り→歌を音程の幅で表す。1・2回目は3半音の幅に収め、3回目は中間、4回目でフックになる。
Outroはこの順を逆にたどる。

音域はA3–D5である。D5はLastChorusの「なった」の1回だけで、F#m上の6度から5度（C#5）へ解決させる。
各ブロックの音域は、AがC#4–A4、BがE4–C#5、ChorusがE4–C#5、BridgeがA3–F#4である。

3拍半以上の長い音は母音a、o、eにだけ置いた。例外はフック末尾の「い」で、企画どおりである。
行末がuの行は、行内のa、o、eを伸ばす形にした。たとえば「巻き戻す」の行では「ど」の音を伸ばした。
無声化しやすい音（「ひとつ」の「つ」、Bridgeの「すこし」など）は16分か8分の短い音で通した。
すべての行の間に16分以上の休符を入れ、息継ぎを確保した。

## パートと編成

| トラック | 役割                                  | 鳴るセクション                         |
| -------- | ------------------------------------- | -------------------------------------- |
| Vocal    | 歌。ノートに歌詞（ひらがな）を付けた  | 全体                                   |
| Drums    | セクションごとの型                    | Intro以外。Bridgeは終盤4小節の鼓動だけ |
| Bass     | 全音符、2分、8分、裏打ちなど          | Intro・Bridge以外                      |
| Pad      | 全音符の和音。声部は最小移動でつなぐ  | ほぼ全体                               |
| Saw      | サビの刻み（3+3+2のシンコペーション） | Chorus、Drop（裏拍）、LastChorus       |
| Arp      | 16分のアルペジオ                      | Chorus2、LastChorus                    |
| Piano    | 分散和音                              | A、B、Outro                            |
| Lead     | フックの旋律、歌の1オクターブ上       | Drop、Break末尾、LastChorus            |

反復の中の差分は1〜2要素に抑えた。Chorus2はChorus1にArpを足しただけで、LastChorusはさらにLeadのオクターブ重ねを足して延長した。

ドラムの型は次のとおりである。

- A1前半: ハーフタイムのリムとハット。後半からキックが入る
- B: 4つ打ちから、スネアが4分、8分、16分へ詰まる。最終小節の4拍目は全パート無音
- Chorus: キックを1拍、2拍裏、3拍に置き、スネアとクラップは2・4拍。4小節ごとにクラッシュとタムのフィル
- Drop: 4つ打ち、裏のオープンハット、ベースの裏打ち
- Break: キック4分、8分、スネア16分、32分と2小節ごとに加速し、112小節目は完全な無音

## 歌声モード

vocal.tsv のmode列に、OpenUtauで使う歌声モードの案を入れた。
IntroとBridge前半はSoft、Bridge後半はEmotional、A・BはStandard、Chorus・Drop・BreakはPowerである。

## 割り付け表（vocal.tsv）

1行が1モーラである。小節、拍、tick（4分音符=480）、長さ、音名、MIDI番号を持つ。
OpenUtauのUSTXも4分音符=480 tickなので、tickの値をそのまま使える。
促音「っ」は kind=closure の行にした。音程は持たない。USTXへ変換するときは休符にするか、前の音を短くする。
変換の方法は歌声工程で決める。

## 合成音プレビューの測定

FluidSynthとGM音源で書き出し、評価基準v1と同じ定義で測った。音色はGMのままで、ミックスはしていない。
帯域や重心は音色で決まるので、ここでは目安にしない。見るのはセクション間の音量差だけである。

| セクション | 短時間LUFSの平均 |
| ---------- | ---------------- |
| Intro      | -27.3            |
| A1         | -22.4            |
| B1         | -18.8            |
| Chorus1    | -9.7             |
| Drop1      | -9.3             |
| Bridge     | -24.4            |
| Break      | -16.9            |
| LastChorus | -7.0             |

BridgeとLastChorusの差は17.4dBある。
LRAは18.2で、帯の上限14.1を超える。ミックスで圧縮すれば縮む量なので、作曲ではこのままにする。
スペクトル重心は689Hzで、帯の3342–4920Hzより大きく低い。GM音色に高域が少ないためである。
ミックスではシンセとシンバルで高域を足す必要がある。
